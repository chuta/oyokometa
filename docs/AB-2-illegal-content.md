# AB-2 — Illegal content procedure (draft)

Launch blocker for public R1. Counsel must confirm reporting obligations for the operating jurisdiction before go-live.

1. Uploader attests they may lawfully submit the file (first-use checkbox; Terms).
2. Malware scan runs before decode. Files that fail are deleted from primary storage; no staff re-distribution.
3. Suspected child sexual abuse material: quarantine the object (no preview generation), block the session, retain only what the law requires, report through the designated channel. Staff must not download or forward the file.
4. Other illegal content: same quarantine; trust-and-safety review with a logged reason.
5. Public share/verify pages (R2/R3) expose Report abuse with a 1-business-day first response target.
6. Review hours and the named reviewer are owner decisions (PRD §14 item 15).
