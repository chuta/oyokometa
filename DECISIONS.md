# Decision notes

Substitutions and defaults from PRD v3.0 §10 / §14. Recorded as required by §13.2.

| Concern | PRD default | Choice | Note |
| --- | --- | --- | --- |
| Web | Next.js + Tailwind | Next.js 15 App Router, Tailwind 3 | SSR public pages |
| API | Node REST + OpenAPI | Hono on Node | Same contract |
| Queue | Redis-backed | BullMQ | Stage retry + DLQ |
| Storage | S3-compatible | AWS SDK + MinIO locally; production currently uses `STORAGE_DRIVER=fs` on the Fly volume `okm_data` | Single-machine API with the worker inline (`INLINE_WORKER=true`, no Redis). Move to S3/R2 before running more than one machine. |
| Retention | Delete originals on schedule | Hourly job in the API process: bytes and previews deleted at `retain_until` (signed-in 30 days, anonymous 1 day); anonymous analyses purged after 24 hours. Evidence and hashes kept. | Runs only while the machine is up (`auto_stop_machines`); the first run is 60 s after boot. Provenance thumbnails are separate per-record copies, so retention never breaks a public record. |
| Metadata | ExifTool | ExifTool when present; `exifr` fallback in local/dev | Producer version recorded |
| C2PA | Official SDK | `@contentauth/c2pa-node` `Reader` against C2PA 2.3; Trust List via `verifyTrust`; five AN-25 states from `validation_status`. Create still does not embed C2PA (PR-7) until a Trust List CA certificate. API/worker Node 22 for the native module. | Never a custom parser |
| Signing | Cloud KMS | `KmsSigner` interface: AWS KMS (`AWS_KMS_KEY_ID` + `SIGNING_PUBLIC_KEY_PEM`) or ECDSA P-256 PEM | Production signs with AWS KMS key `alias/oyokometa-signing` (eu-west-1, ECC_NIST_P256), kid `okm-kms-1`, defined in `infra/aws/signing-key.yaml` (stack `oyokometa-signing`). The API authenticates as IAM user `oyokometa-signer`, which may only `kms:Sign`, `kms:GetPublicKey` and `kms:DescribeKey` on that key. Public key: `infra/aws/signing-public.pem`. The earlier env key `okm-fly-1` is published as retired via `SIGNING_RETIRED_KEYS_JSON`. Without KMS, production refuses to sign unless `SIGNING_ALLOW_ENV_KEY=true`. To rotate: create a new key, publish the current one as retired (`pnpm --filter @oyokometa/api signing:retired-key`, or take its public JWK from `/.well-known/oyokometa-keys.json`), then set the new `AWS_KMS_KEY_ID`, `SIGNING_PUBLIC_KEY_PEM` and `SIGNING_KEY_ID`. Records verify against the key they name, so older records stay valid. |
| TSA | RFC 3161 | DigiCert (`TSA_URL=http://timestamp.digicert.com`). Request carries a SHA-256 imprint, nonce and `certReq`; the reply must be granted, match the imprint and nonce, and its CMS signature must verify (pkijs). The TimeStampToken DER is stored. | Production never falls back to the platform clock: no verified token, no record, and the credit hold is released. TSA certificate chain is not yet validated against a pinned root. Development without `TSA_URL` records a labelled platform-clock assertion. |
| Payments | Paystack/Flutterwave + Stripe | Direct bank transfer with unique `OKM-` narration code. **I have sent the transfer** only moves the payment to `awaiting_match`. An admin or finance user confirms the deposit (exact amount + where it was seen) to grant credits, or rejects it. | Amount and pack come from `credit_products`. Credits granted once per payment id, never from a client-sent balance. Paid payments can be reversed. |
| Paid actions | Price + balance + confirm | Every paid action (Deep Analysis, upgrade, report, registration) shows price, balance and balance after, and the client must echo `expected_credits`. If it differs from the current price the API returns `409 price_changed` and charges nothing. | Prices with a future `effective_from` are ignored until they take effect. |
| Malware | Scan then decode | ClamAV (`clamd` INSTREAM) on a private Fly app `oyokometa-clamav` (`infra/fly/clamav.toml`). Production fails closed: no scanner or a scanner error stops the analysis with `service_unavailable` and no charge. | Every scan result (clean, flagged, skipped) is stored as a raw output. `MALWARE_SCAN_REQUIRED=false` is the only way to skip in production. |
| Account deletion | Self-service | Account page: password, or an emailed link for link-only accounts, plus typing DELETE. Removes images, analyses, reports and share links; withdraws provenance records with a signed event; anonymises the user row; redacts audit rows naming the email. | Ledger and payment rows stay for accounting against the anonymised user. Unused credits are forfeited. |
| Audit log | Append-only | Trigger blocks UPDATE, DELETE and TRUNCATE on `audit_log` (migration `0006_phase0`). The only exception is redaction during account erasure, inside a transaction that sets `oyokometa.audit_redaction`. | |
| Auth | Supabase Auth / OAuth | Custom sessions in Postgres: username or email + password (scrypt), and email magic links via Resend | Supabase Auth email templates exist in `docs/` but are not used by the app. |
| Reports | PDF renderer | `pdf-lib` in the API process | |
| Observability | Logs, metrics, alerts | Fly logs only (structured JSON lines) | No metrics or alerting yet. |
| Database | PostgreSQL | Supabase Postgres (`vpvhshoxwaorrwtaxvdb`) | App still uses Drizzle over `DATABASE_URL`. Data API locked with RLS; Hono uses the database URI. |
| AI labels | Off until §12 gate | `config.ai_labels_enabled` default false. Detector scores are stored and are not shown, and they do not change a finding until the gate is recorded. | AN-32 |
| AI detectors | One on Quick Scan, two on Deep Analysis | Quick Scan and Deep Analysis call a private Fly app (`oyokometa-detector`, `infra/detector/fly.toml`) running Community Forensics ViT-Small (`adapter-a`, ONNX v1.1). Deep Analysis also calls Sightengine `genai` and `deepfake` in one request (`adapter-b`). A Sightengine timeout or error releases the Deep Analysis hold and marks AI analysis unavailable. The vendor name stays in this note and the privacy notice, not in analysis output. | No watermark detector is available. Labels stay off until the §12 corpus passes. Sightengine credentials are `SIGHTENGINE_API_USER` and `SIGHTENGINE_API_SECRET`. |
